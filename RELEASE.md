# Open Space v0.4.6

- **Français par défaut.** L'anglais reste disponible dans Paramètres → Général.
- **Rien à payer, aucun compte.** Ni offre Pro, ni sponsor, ni voix facturée.
- **Tout reste sur votre machine.** Vos agents, leur mémoire et vos projets.

Open Space transforme l'agent de code en ligne de commande que vous utilisez déjà (Claude Code, Codex, un modèle local…) en un bureau d'agents qui travaillent pour vous, dirigés par votre clone.

## Premier lancement

Les installateurs ne sont pas signés par Apple ni par Microsoft, donc le système vous prévient la première fois.

- **macOS** : ouvrez le `.dmg` et glissez Open Space dans Applications. Si macOS refuse de l'ouvrir, allez dans Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ». S'il dit que l'app est endommagée, tapez dans le Terminal `xattr -cr "/Applications/Open Space.app"` puis relancez-la.
- **Windows** : si « Windows a protégé votre ordinateur » s'affiche, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».

Sur Mac, une app non signée ne peut pas s'installer toute seule : quand une nouvelle version sort, l'app vous la signale et vous téléchargez le nouveau `.dmg`.
